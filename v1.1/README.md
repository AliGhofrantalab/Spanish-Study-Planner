\# 🇪🇸 Spanish Study Planner – v1.1



An improved version of the Spanish Study Planner, designed to make organizing daily Spanish learning tasks easier.



\## 🚀 Live Demo



\[Open Spanish Study Planner v1.1](https://alighofrantalab.github.io/Spanish-Study-Planner/v1.1/)



\## ✨ Features



\- ➕ Add new study tasks

\- ⌨️ Press Enter to add tasks quickly

\- ✅ Mark tasks as completed

\- 🗑️ Delete tasks

\- 🔢 Automatic task numbering

\- 📊 Task counter

\- 📋 Scrollable task list

\- 🎨 Improved user interface
