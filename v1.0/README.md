\# 🇪🇸 Spanish Study Planner – v1.0



A simple task management application designed to help Spanish learners organize their daily study activities.



\## 🚀 Live Demo



\[Open Spanish Study Planner v1.0](https://alighofrantalab.github.io/Spanish-Study-Planner/v1.0/)



\## ✨ Features



\- Add new study tasks

\- Press Enter to add tasks quickly

\- Display tasks in a scrollable list

\- Simple and clean user interface



\## 🛠️ Built With



\- HTML5

\- CSS3

\- Vanilla JavaScript
