\# 🇪🇸 Spanish Study Planner – v1.2



An interactive web application for organizing and managing daily Spanish learning tasks.



This version introduces improved task management features and Local Storage to save tasks in the browser.



\## 🚀 Live Demo



\[Open Spanish Study Planner v1.2](https://alighofrantalab.github.io/Spanish-Study-Planner/v1.2/)



\## ✨ Features



\- ➕ Add new study tasks

\- ⌨️ Press Enter to add tasks quickly

\- ✏️ Edit existing tasks

\- ✅ Mark tasks as completed

\- 🗑️ Delete tasks

\- 🔢 Automatic task numbering

\- 📊 Task counters (Total, Completed, Remaining)

\- 💾 Save tasks using Local Storage

\- 📋 Scrollable task list



\## 🛠️ Built With
